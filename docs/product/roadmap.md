# Roadmap

## Version 1

- Monorepo and CI.
- Exact variant catalog foundation.
- Deterministic compatibility engine with direct, adapter, exclusion, rating, and dimensional paths.
- Web builder vertical slice.
- Supabase authentication and authenticated cloud build persistence.
- Private Armory foundation and RLS tests.
- Admin catalog and verification workflows.

## Version 1.5

- Mobile Expo client.
- Broader seed catalog and import tooling.
- Retailer offers, price freshness, saved searches, comparison, and maintenance reminders.
- Moderated verified-fitment reports.

## Version 2

- Manufacturer portal and feeds.
- Mature dimensional envelopes and collision detection.
- 3D asset anchors and glTF pipeline.
- Local encrypted vault and offline Armory.

3D and retailer integrations remain extension points until deterministic data quality and the exact-variant loop are proven.
